# Chrome Extension: Screenshot
Capture high-quality screenshots of webpages quickly and easily. Save visible page content for reference, sharing, documentation, design feedback, bug reporting, and more.

## Local Development
To run the `Chrome extension` locally, open `Chrome` and enter the URL of: `chrome://extensions`. From here, enable `Developer mode` and click `Load unpacked`. Select the folder where the extension code is saved.

Once the extension has been installed locally:

### Adding Extensions to Chrome
To add an extension to Chrome, open up the browser and click the icon near to the address bar. This looks like a jigsaw piece.

<img width="1617" height="150" alt="Icon to add an extension to Chrome." src="https://github.com/user-attachments/assets/1bb67b97-2725-42d9-91fa-67b00ab19ed0" />

Add the extension to the browser by selecting the one listed. This can be pinned to the toolbar.

<img width="1620" height="505" alt="Selecting the extensiom to use." src="https://github.com/user-attachments/assets/bb64e70b-1f9b-49cb-8f7f-03686f85bb16" />

Once selected, the extension will be added.

<img width="1618" height="197" alt="The extension has been added to the browser." src="https://github.com/user-attachments/assets/c3af4925-a6b1-44b4-9723-cf2c750de523" />

The extension will show a popup and button allowing a screenshot to be generated when clicked:

<img width="1622" height="366" alt="The popup that a user will see when they use the extension." src="https://github.com/user-attachments/assets/716993d7-97cd-4d7e-a08a-a27a98a09949" />

The screenshot is then available as a `.png` file in downloads. This can then be moved elsewhere and the screenshot image can then be used.

<img width="1619" height="237" alt="Screenshot 2026-09-03 at 10 12 32" src="https://github.com/user-attachments/assets/78a6fcb4-ba3b-4402-90de-15d87508d985" />
